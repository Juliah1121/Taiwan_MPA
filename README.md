# 台灣海洋保護區成效儀表板

整合 **水質、海洋廢棄物、生物多樣性（魚類環境 DNA）、執法強度** 四項指標，評估臺灣 71 處海洋保護區（MPA）的成效，並進一步分析成效和下列因素的關係：

- 保護區分類（類型、法源、IUCN 分類）
- MPA Guide 保護等級
- 面積、成立年份
- 鄰近人口與漁業壓力
- 管理投入（巡守）

> 本儀表板為依公開資料所做的**非官方評估**，用於找出管理優先順序，不等同主管機關的官方成效分級。

## 線上瀏覽

本機瀏覽需透過本機伺服器（瀏覽器不允許直接用 `file://` 讀取 CSV）：

## 主要發現

- 9 處良好、33 處尚可、19 處待加強、7 處不佳、3 處資料不足；四面向平均：水質 78、生物多樣性 59、海廢 52、執法 42。
- 綜合成效與保護區類型、法源、IUCN 分類、保護等級、面積、成立年份都**沒有顯著關聯**。
- 漁業與養殖廢棄物是生態環境分數最強的預測因子；人口密度主要影響海廢；巡守時數與生態成果無正相關。
- 生物多樣性評比：良好 14、尚可 15、待加強 15、不佳 3，24 處只有棲地資料。13 處有珊瑚礁體檢數據，最近一次覆蓋率達優良（≥50%）的只有綠島。
- 集群分析分出四種成效型態：均衡良好 24、環境佳但缺管理 14、有管理但海廢重 25、水質差全面落後 5；型態與法定類別幾乎無關（Cramér's V＝0.21，置換檢定 p＝0.90），同類別保護區分散在不同型態。
- 保護區內藍碳約 33 萬公噸碳，東沙海草床占 61%；全國紅樹林只有約一半在保護區內。

## 評分方法（各面向 0–100 分）

生物多樣性評比另計，不改動下列綜合分：棲地多樣性（主要 1、局部 0.5，滿 3 為 100）、珊瑚健康（最近覆蓋率 ×1.6＋20，減少扣 10）、藍碳（A 級 100、B 級 70）與魚類 eDNA 取有資料者平均。


| 面向 | 資料 | 計分 |
|---|---|---|
| 水質 | 海保署國家與地方測站（保護區內或 1 km 內） | 近 3 年現況（良好 85／注意 55／不佳 25）＋長期趨勢調整（改善 +15、持平 0、互有增減 −5、變差 −15） |
| 海廢 | 海岸淨灘監測 2020–2024 | 平均 kg／次取對數後的全國百分位（越少越高）＋趨勢調整 |
| 生物多樣性 | 保護區站點魚類 eDNA 2021–2024 | 同棲地（礁岩／河口）內每次採樣分類單元數百分位，外來種占比高者扣分 |
| 執法 | MPA 平台巡守與執法通報 112–114 年 | 有巡守或案件基本分＋巡守時數百分位＋取締與處分率（平滑處理） |

- 綜合分為有資料面向的平均。
- 等級：≥70 良好、55–69 尚可、40–54 待加強、<40 不佳。

## 資料來源

- 海洋委員會海洋保育署：海域水質監測、海岸淨灘監測、臺灣周邊海域魚類 eDNA 調查（保護區站點）、海洋保護區平台巡守與執法通報
- MPATable1：臺灣海洋保護區之類型、IUCN 分類與保護等級（檢核修正版）
- 珊瑚礁體檢：中研院（2008）、台灣環境資訊協會（2023）、Reef Check Taiwan（2024–26）
- 藍碳：海保署 2024 年藍碳生態系調查報告（2023 年面積）× 全國平均碳密度
- 鄉鎮人口：Wikipedia「List of townships/cities and districts in Taiwan」（頁面未標資料年份）

## 限制

- eDNA 只涵蓋 40 處，且多為單次採樣、只記錄物種是否出現。
- 執法「零查獲」可能是無違規，也可能是沒查到。
- 海廢測點座標依地名推定。
- 漁業壓力以海廢組成作為替代指標，不是實際的漁撈努力量。
- 資料為橫斷面，只能看關聯，不能推論因果。
