# 台灣海洋保護區成效儀表板

整合 **水質、海洋廢棄物、海洋生物多樣性（實地調查紀錄＋環境 DNA）、執法強度** 四項指標，評估臺灣 71 處海洋保護區（MPA）的成效，並進一步分析成效和下列因素的關係：

- 保護區分類（類型、法源、IUCN 分類）
- MPA Guide 保護等級
- 面積、成立年份
- 鄰近人口與漁業壓力
- 管理投入（巡守）

> 本儀表板為依公開資料所做的**非官方評估**，用於找出管理優先順序，不等同主管機關的官方成效分級。

## 線上瀏覽

在 GitHub Pages 啟用後，可直接開啟 `index.html`。設定方式：**Settings → Pages → Branch: `main` / root**。

本機瀏覽需透過本機伺服器（瀏覽器不允許直接用 `file://` 讀取 CSV）：

# 開啟 http://localhost:8000

## 主要發現（v3，2026-11-03）

- 良好 7、尚可 35（含暫評 1）、待加強 23（含暫評 1）、不佳 4、資料不足 2；四項資料齊全 46 處。四面向平均：水質 78、生物多樣性 59、海廢 52、執法 42。
- 綜合分最高（≥3 面向）：石梯坪 81、墾丁 74、觀新藻礁 73、鹽寮 73、綠島海參坪 72、萬里 71。
- 生物多樣性納入 TBN 實地紀錄後，有分數的保護區由 40 處增至 57 處；最高為東沙 94、台江 93、海生館 88、綠島 87。東沙由資料不足變為尚可（暫評，69）。
- 綜合成效與保護區類型、法源、IUCN 分類、保護等級、成立年份大致無關；60 項檢定中唯一 q<0.1 的是**面積越大，生物多樣性分數越高**（ρ=0.43）。
- 漁業與養殖廢棄物仍是生態環境分數最強的預測因子；人口密度主要影響海廢；巡守時數與生態成果無關（ρ≈0）。
- 集群分析分出四種成效型態：均衡良好 31、有管理但海廢重 23、環境佳但缺管理 10、水質差且管理弱 3；型態與法定類別幾乎無關（Cramér's V＝0.19，置換檢定 p＝0.94）。
- 保護區內藍碳約 33 萬公噸碳，東沙海草床占 61%；全國紅樹林只有約一半在保護區內。

## 評分方法（各面向 0–100 分）

| 面向 | 資料 | 計分 |
|---|---|---|
| 水質 | 海保署國家與地方測站（保護區內或 1 km 內） | 近 3 年現況（良好 85／注意 55／不佳 25）＋長期趨勢調整（改善 +15、持平 0、互有增減 −5、變差 −15） |
| 海廢 | 海岸淨灘監測 2020–2024 | 平均 kg／次取對數後的全國百分位（越少越高）＋趨勢調整 |
| 生物多樣性 | TBN 海洋魚類與蝦蟹類紀錄（含國家公園長期調查）、魚類 eDNA 2021–2024（先期試驗）、珊瑚礁體檢、藍碳、生態系類型 | 五分項加權平均：物種紀錄 1（已確認物種＋eDNA 獨有×0.5，同棲地百分位 20–100，IUCN 受脅物種加 5–10）、珊瑚健康 1、藍碳 1、棲地多樣性 1、eDNA 試驗 0.5；至少要有物種紀錄（≥10 種）、珊瑚或 eDNA 一項實際觀測才給分 |
| 執法 | MPA 平台巡守與執法通報 112–114 年 | 有巡守或案件基本分＋巡守時數百分位＋取締與處分率（平滑處理） |

- 綜合分為有資料面向的平均。
- 等級：≥70 良好、55–69 尚可、40–54 待加強、<40 不佳；只有兩面向有資料標「暫評」，少於兩面向標「資料不足」。
- 成效排名不再列出海保署 2022 年分級。

## 資料來源

- 海洋委員會海洋保育署：海域水質監測、海岸淨灘監測、臺灣周邊海域魚類 eDNA 調查（保護區站點）、海洋保護區平台巡守與執法通報
- 台灣生物多樣性網絡（TBN）海洋生物紀錄，含國家公園生物多樣性資料庫（墾丁、台江、東沙環礁、澎湖南方四島）
- 保護區範圍：海委會 2017 年海洋保護區圖層
- MPATable1：臺灣海洋保護區之類型、IUCN 分類與保護等級（檢核修正版）
- 珊瑚礁體檢：中研院（2008）、台灣環境資訊協會（2023）、Reef Check Taiwan（2024–26）
- 藍碳：海保署 2024 年藍碳生態系調查報告（2023 年面積）× 全國平均碳密度
- 鄉鎮人口：Wikipedia「List of townships/cities and districts in Taiwan」（頁面未標資料年份）

## 限制

- 物種紀錄反映「已知程度」，受調查努力量與面積影響；帶狀小保育區常因座標精度不足而無紀錄。
- eDNA 為經費有限下的先期試驗，多為單次採樣、只記錄物種是否出現，權重減半。
- 執法「零查獲」可能是無違規，也可能是沒查到。
- 海廢測點座標依地名推定。
- 漁業壓力以海廢組成作為替代指標，不是實際的漁撈努力量。
- 資料為橫斷面，只能看關聯，不能推論因果。
